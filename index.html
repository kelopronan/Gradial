Groq API Key (AI Subtitles)

Enter your Groq API key (`gsk_...`) to enable speech-to-text AI subtitle generation for video clips.

Not Checked
How to get a Groq API Key (Whisper Large v3 Turbo)
  1. Go to console.groq.com/keys and sign up or log in for free.
  2. Click "Create API Key", name it (e.g., Gradial AI Subtitles), and copy your key (gsk_...).
  3. Paste your key into the field above and click "Check API Key". The high-speed Whisper Large v3 Turbo AI model will automatically generate subtitles for your videos!
